# JavaScript Functions Practice

A collection of JavaScript function exercises designed to strengthen problem-solving skills, improve code quality, and deepen understanding of core JavaScript concepts.

## 🎯 Purpose

This repository is dedicated to practicing and mastering JavaScript functions through progressively challenging exercises.

The goals are to:

- Improve logical thinking and problem-solving skills.
- Write clean, readable, and maintainable code.
- Learn modern JavaScript syntax and best practices.
- Prepare for technical interviews and coding assessments.
- Build confidence with functional programming concepts.

---

## 📚 Topics Covered

### Fundamentals
- Function Declarations
- Function Expressions
- Arrow Functions
- Parameters & Arguments
- Default Parameters
- Rest Parameters
- Return Values
- Scope

### Intermediate
- Higher-Order Functions
- Callbacks
- Closures
- Recursion
- Array Methods
  - `map()`
  - `filter()`
  - `reduce()`
  - `find()`
  - `some()`
  - `every()`

### Advanced
- Function Composition
- Currying
- Memoization
- Debouncing
- Throttling
- Pure Functions
- Functional Programming Patterns
